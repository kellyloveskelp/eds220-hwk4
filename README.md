# Using False Color Imagery to Visualize Fire Scars
## Eaton-Palisades Fires in Los Angeles, CA, Janurary 2025

### Goal of the project

**Create a false color image of the Eaton and Palisades Fires using remote sensing data, highlighting the fire scar and exploring how coding and data visualization support environmental monitoring [(Project Page)](https://meds-eds-220.github.io/MEDS-eds-220-course/assignments/assignment4-palisades-eaton-fires.html#netcdf-data-import-and-exploration).**

### In this repo
#### data/
- land-cover-stats-data/Eaton_Perimeter_20250121
  - Shapefile of Eaton Fire extent 
- land-cover-stats-data/Palisades_Perimeter_20250121
  - Shapefile of Eaton Fire extent 
- landsat8-2025-02-23-palisades-eaton.nc
  - netCDF file containing Landsat satellite imagery of Los Angeles, CA after Janurary 2025

### Data Access
All data housed in this repository can be downloaded from the EDS-220 course data folder [on Google Drive](https://drive.google.com/drive/folders/1USqhiMLyN8GE05B8WJmHabviJGnmAsLP) and can be read using `geopandas`,  `xarray`, oe related packages.
